# PowerHub

Shizuku-powered Android power menu.

## Features
- Reboot
- Reboot to recovery
- Reboot to bootloader / fastboot
- Power off
- Turn screen off
- Shizuku connection and permission status
- Light and dark themes with teal accents
- Adaptive launcher icon with a white power symbol on a teal background

## Requirements
- Android 8.0 or newer
- Shizuku installed, running, and authorized
- No root required

## Build APK through GitHub Actions
1. Push changes to the main branch, or open Actions and run the Build PowerHub APK workflow manually.
2. Open the completed workflow run.
3. Download the PowerHub-debug artifact.
4. Extract app-debug.apk and install it.

The APK is generated by GitHub Actions and is not committed to the source tree.

## Notes
Power commands depend on the Android build and OEM firmware. Recovery and bootloader commands may be restricted by some devices. Screen-off sends the standard power key event. Shizuku may need to be started again after reboot when using wireless debugging.
